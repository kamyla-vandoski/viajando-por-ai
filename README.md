# ✈️ A Arte de Viajar

## Descrição

Este projeto consiste em uma página informativa sobre viagens e turismo,
desenvolvida como parte de um projeto acadêmico.

A página apresenta informações sobre a importância de viajar, os benefícios
das viagens, dicas de planejamento e algumas sugestões para aproveitar melhor
as experiências em diferentes destinos.

## 🌎 Tema escolhido

O tema escolhido foi **Viagens**, um assunto que desperta meu interesse
porque permite conhecer novos lugares, culturas, pessoas e experiências.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## 📱 Responsividade

A página foi desenvolvida para funcionar em diferentes tamanhos de tela,
incluindo computadores, tablets e smartphones.
